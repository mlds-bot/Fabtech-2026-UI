MinchMod Fabtech 2026 Scout

1. Extract this ZIP.
2. Upload and replace all files in your existing GitHub Pages repository.
3. Commit to main.
4. Open the live site once while online. Refresh if the old version appears.
5. If the installed Home Screen app remains old, remove its icon, open the updated site in Safari/Chrome, and add it again.

Features: offline booth route, permanent Add Vendor button, scoring, opportunity capture, report generation, copy, print/save PDF, HTML report download, and JSON backup/restore.

All user data is local to that phone and browser. It does not sync. Use Backup my data at the end of each day. Clearing browser data or deleting the web app can erase entries.

Vendor list: Edit FABTECH_Vendors.xlsx and use Menu > Import Excel vendor list.
Use Day 1 or 2. Questions go in one cell, separated by line breaks or semicolons.
An import replaces the spreadsheet route. It keeps scores and notes when Day, Vendor Name, and Booth Number still match exactly. Back up your data before renaming vendors or booths.

Welcome screen: opens when the app launches. Tap Start scouting to see the route. Menu > Welcome screen returns to the front page.
